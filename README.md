# ChainLucent

ChainLucent dynamically optimizes distributed networks through auto-configurable, real-time processing and adaptive auto-scaling hubs and gateways.

With ChainLucent, you get a lightweight tool that stays out of your way.

**What you get**

- ChainLucent dynamically optimizes distributed networks
- through auto-configurable, real-time processing and
- adaptive auto-scaling hubs and gateways

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainLucent.git`
2. `cd ChainLucent`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainLucent is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
